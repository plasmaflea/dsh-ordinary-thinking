# 🧪 预设答案假设倒推法 · 模拟版

**简称**：倒推图·模拟（产物：思考轨迹表 + 通道记账）／倒推法·模拟（动作）
**技能 id**：`presupposed-answer-hypothesis-backderivation-simulation` ＝ 预设答案·假设·倒推法 ＋ `simulation`（模拟版）

**与主仓库同名技能的分工**：主仓库那版是**审计器**——判一段已经产生的推理可不可信；这一版是**模拟器**——把普通人的思考过程跑一遍，看它怎么产生结果。同一个模型，两种用法，两套产物，互不替代。

## 一、核心论点：普通人不是不能处理问题

倒推法（先有答案、再补理由）确实能得出正确答案。它走的是三条通道：

| 通道 | 机制 | 例子 |
|---|---|---|
| **L 运气** | 假设恰好为真。选项少、先验强时命中率并不低 | 卡顿先猜内存不足——而多数机器真的是内存不足 |
| **A 迟到调整** | 反例出现后不改假设，改**假设的适用边界**：「不是所有情况，是这种情况」。本质是推迟了的分类讨论 | 先断言「都是缓存问题」，连错两次后收窄成「只在冷启动时是缓存问题」 |
| **R 改题面** | 把问题重述成假设能解释的那个问题 | 问「为什么付费率低」，答成「付费率要高起来需要什么」 |

所以：**倒推法不是错误方向，是低成本探索策略**。它的失败率来自「假设集不全 + 不做证伪」，不来自方向。

研究它，要量的是这三条通道各占多少，而不是先验地判它错。

## 二、这个技能是 / 不是

| 是 | 不是 |
|---|---|
| 生成并记录思考轨迹 | 纠正别人的推理（那用审计版） |
| 计算成功通道占比与失效面 | 给答案背书（运气好 ≠ 方法好） |
| 可重复的对照实验装置 | 一次性的说服工具 |

## 三、语法：这一版填「轨迹」，不填「判据」

| 列 | 内容 |
|---|---|
| H | 本轮所持的假设 |
| E+ | 若 H 成立应看到什么 |
| E± | 实际看到了什么 |
| 偏差处置 | **解释掉 / 改边界 / 改题面 / 放弃换假设 / 无视**（五选一，必填） |
| 是否仍成立 | 是 / 否 / 边界内是 |
| 通道标记 | L / A / R / —（仅当本步促成了最终正确时标，且必须在**当步**标） |

与审计版的两处关键差别：

1. **没有「反例条件」列**——普通人压根不写它。这不是遗漏，是要观察的事实本身，不能替他补上。
2. **允许「解释掉」和「改边界」存在**，且要如实计数。审计版会把这两种判为走形；模拟版必须让它们发生，否则模拟出来的不是普通人，是稻草人。

## 四、三种运行模式

### 1. 单跑（single-run）——复现一次真实思考

从头走到结论，每步一行。产出：轨迹表 + 通道归因。
判据：**过程是否合规不重要，结果靠哪条通道才对重要。**

### 2. 蒙特卡洛（many-run）——把运气变成数字

固定题面与证据，只随机化「第一轮选了哪一支假设」（按先验加权），跑 N ≥ 20 次。

- 命中率 `p̂ = 正确次数 / N`
- 通道分解 `p̂ = P(L) + P(A) + P(R) + P(真推理)`
- 对照组：在第 1 步注入一条硬反例，看 `p̂` 掉多少——这个差值就是「迟到调整」的贡献量

### 3. 对撞（head-to-head）——与主仓库三张图同题对照

| 指标 | 倒推法·模拟 | 三张图 |
|---|---|---|
| 命中率 | `p̂` | `p̂'` |
| 平均步数 / token | | |
| 结论可解释性 | 差（理由是后补的） | 高（负边留档） |
| 出错时能否定位 | 不能（不知道漏了哪一支） | 能 |

**必须报告的负结果**：若倒推法在某类题面上与结构化方法打平，那不是三张图没用，而是**这类题面本来就靠先验就能中**。这条对主仓库的论文是直接可引用的负结果，不许藏。

## 六、风险与边界

1. **稻草人化**：把倒推法写成「必然失败」的滑稽版本，实验就废了 → 必须给 L / A / R 三条通道足够的出手机会。
2. **归因偏乐观**：事后把成功全算成「真推理」→ 通道标记必须当场标，禁止回填。
3. **样本太小**：N < 20 的命中率只能当轶事，不能当结论。
4. **越界背书**：模拟出「这次对了」≠ 方法可靠，结论句必须带压测警告。
5. **替代不了审计版**：要判一段现有推理可不可信，回主仓库用审计版。

## 七、与主仓库的关系

- 主仓库 `dsh-thinking-models`：三张图 + 审计器，回答「怎么想才对」。
- 本仓库：只有倒推法，只做模拟与测量，回答「普通人怎么想、为什么有时也对」。
- 两个版本可同时安装：技能 id 不同（`…-backderivation` / `…-backderivation-simulation`），目录与 `name` 都不冲突。
